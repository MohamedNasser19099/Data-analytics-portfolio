# Pizza Sales Performance Dashboard

## Overview
This project analyzes The Sales performance of pizzas to understand revenue trend, product performance, customer behavior using an interactive Power BI dashboard.

## Business Problem
Management needs a clear and simple way to aware of pizza sales, be able to know high and low performing products, and enhance the prices, promotions and menu strategy.

## Data Source
The dataset contains pizza sales transactions, order date, pizza category, size, quantity, and revenue.
The data was analyzed using sql and visualized in Power BI.

## Tools Used
-SQL
-Power BI

## Key KPIs
-Total Revenue: 817.86k
-Total Orders: 21k
-Average Order Value: 16.82
-Total Pizzas Sold: 50k
-Average Pizzas per Order: 2.32

## What I Did
-Analyzed the data using SQL
-Cleaned and transformed data in power BI (Power Query)
-Built measuers and KPIs using DAX
-Designed interactive dashboard with filters by time, category, and product.

## Key Insights
-Friday has the highest number of orders, While Sunday has the lowest
-January is the strongest month for sales and february is the weakest
-Classic pizza generates the highest revenue
-veggie pizza generates the lowest revenue
-Thai chicken is the top-performing product
-Brie Carre Pizza is the lowest-performing product
-Pizza sizes are sold in nearly equal proportions and indicating weak upselling.

## Business Value Added
-Helps management to know peak sales months and days
-Supports data-driven decisioins for promotions and staffing
-Improves menu optimization by highlighting top and low performance products
-Highlight opportunities to improve average order value by upselling
